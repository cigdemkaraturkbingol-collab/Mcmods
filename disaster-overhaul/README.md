# Disaster Overhaul

Minecraft dünyasına önceden işaret veren, aşamalı ve otomatik afetler ekleyen mod.

## Bedrock
İlk çalışan afet motoru eklendi:
- Deprem: kamera sarsıntısı ve oyuncuya fiziksel etki
- Meteor yağmuru: oyuncuların çevresine gökten patlayıcı meteor etkileri
- Yangın fırtınası: oyuncuların çevresinde yayılan yangın başlangıçları
- Otomatik olay seçimi
- Uyarı aşaması
- Afetler arasında uzun bekleme süresi
- Komut yazmadan otomatik çalışma

Planlanan sonraki sistemler: hortum, volkan, tsunami, tipi, obruk ve süper fırtına.

## Java
Java sürümü ayrı mod olarak geliştirilecek. Bedrock paketi Java'ya kopyalanmayacak; iki sürüm aynı oyun tasarımını kendi API'leriyle uygulayacak.
